# Helovea — yasal metinler (legal.helovea.app)

Helovea uygulamasının Gizlilik Politikası ve Kullanım Koşulları sayfaları.
Bu depo yalnızca yayın kopyasıdır: dosyalar ana (özel) depodaki `lib/legalTexts.ts`
kaynağından `npm run build:legal` ile üretilir ve buraya kopyalanır. Elle düzenlenmez.
